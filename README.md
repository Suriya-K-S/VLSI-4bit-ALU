# 4-Bit ALU Design Using Verilog HDL

## Project Overview

This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL.

## Operations Supported

* Addition
* Subtraction
* AND
* OR
* XOR
* NOT

## Inputs

* A[3:0]
* B[3:0]
* SEL[2:0]

## Output

* RESULT[3:0]

## Tools Used

* Verilog HDL
* Icarus Verilog
* VS Code
